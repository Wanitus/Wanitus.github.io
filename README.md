## 🛠️ Local Development & Deployment

### 1. Run Locally
Simply open `index.html` or `experience.html` in any web browser:
```bash
# Windows PowerShell
Start-Process .\index.html
```

### 2. Deploy Updates to GitHub Pages
Changes pushed to branch `main` are automatically published to [https://wanitus.github.io](https://wanitus.github.io):
```bash
git add .
git commit -m "Update portfolio content"
git push origin main
```
